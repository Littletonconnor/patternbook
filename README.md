# Patternbook

An interactive notebook of everyday engineering problems (pagination, infinite scroll, debounce, optimistic updates), plus how Linux and Docker work under the hood.

Built with Next.js (App Router) and TypeScript, deployed on Vercel. See [CATALOG.md](CATALOG.md) for the lessons planned.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.
